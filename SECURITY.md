# Security policy

## Supported versions

Security fixes are intended for the current version deployed from the default branch. Older preview deployments are not supported release targets.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** / private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the maintainers privately before publishing technical details. Do not include private identity backups, live invite secrets, or other user data in a report.

Include:
- affected URL, commit, browser, and version where known
- concise impact and reproducible steps
- proof-of-concept details limited to what is necessary to validate the issue
- any suggested mitigation

Please allow time for triage and a fix before public disclosure. This policy is not a guarantee of a response time or a bug-bounty program.
